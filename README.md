# Solterra Grand

A fictional luxury cliffside resort website built with Next.js, TypeScript, and Tailwind CSS. The site features a vertical scroll experience through five resort levels, from the hilltop arrival down to a private beach cove.

**Live:** [solterra-grand.vercel.app](https://solterra-grand.vercel.app/)

## Features

- Multi-level landing page with scroll-based sections (Arrival, Social Hub, Residences, Pools, Beach & Cove)
- Member portal with authentication
- Booking system (create and cancel bookings)
- User profile management
- Responsive across desktop and mobile

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Storage:** Supabase (image hosting, auth, database)
- **Deployment:** Vercel

## Getting Started

```bash
git clone https://github.com/Trowlips/Solterra-Grand.git
cd Solterra-Grand
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

> Note: You'll need to set up your own Supabase project and add the environment variables for auth and storage to work locally.
